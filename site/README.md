# Scientific Python Lab – Unit 3

Interactive class website for *Scientific Computing using Python* (Poojan Shah, RRU) – Unit 3:
**SciPy, statsmodels, SymPy and NetworkX**.

- 27 lessons · 138 marked tasks (1 mark each) · 55 practice quick checks
- Real Python in the browser (Pyodide with SciPy, statsmodels, SymPy, NetworkX)
- Roster-based Google sign-in: only students on the uploaded roster can enter, after confirming their details once
- Topics stay locked until the teacher opens them on `teacher.html`
- Submit answers, then **Final submit** a topic – no changes after that
- `teacher.html`: roster CSV upload, topic lock/open, exam mode, release results, live marks, reopen, CSV export

See **SETUP.md**.
